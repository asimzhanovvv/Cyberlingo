# CyberPath

Тренажёр по курсу Cisco Cybersecurity Essentials в духе Duolingo: карта модулей,
островки-подразделы, чтение теории без потерь и зубрёжка каждого термина в нескольких форматах.

## Запуск

```bash
npm install
npm run dev      # откройте Network URL на телефоне, например http://192.168.1.10:5180
npm run build    # сборка в dist
npm run check    # валидатор контента
```

Для проверки с телефона компьютер и телефон должны быть подключены к одной Wi-Fi сети.
После `npm run dev` откройте на телефоне адрес `Network`, который напечатает Vite.
Если Windows Firewall спросит разрешение для Node.js, разрешите доступ в частных сетях.

## PWA на iPhone

Открыть сайт в Safari, «Поделиться» → «На экран Домой». Приложение ставится иконкой,
работает офлайн, весь контент лежит в бандле.

## Supabase

1. В `.env.local` вставить `VITE_SUPABASE_ANON_KEY` (Project Settings → API keys → anon public).
2. В Supabase → SQL Editor выполнить `supabase/schema.sql`.
3. В Authentication → Sign In / Providers выключить «Confirm email», чтобы входить сразу.
4. Перезапустить `npm run dev`, во вкладке «Профиль» появится форма входа.

Без ключей приложение работает полностью, прогресс просто лежит в браузере.

## Автоимпорт курса

`scripts/import-course.py` превращает выгрузку расширения netacad-extractor
(`cyberpath-data/out/modules/*.json`) в контент приложения:

```
python scripts/import-course.py <путь к out/modules> src/content/auto
```

На выходе `src/content/auto/manifest.json` (список модулей и разделов, грузится сразу)
и `m<N>.json` на каждый модуль (уроки и вопросы, грузятся отдельным чанком при заходе
в раздел). Ручные острова 1.1, 1.2 и 2.1 скрипт не трогает: они живут в .ts и главнее
автоимпорта с тем же номером.

Как ложатся блоки курса:

| В выгрузке | В приложении |
|---|---|
| text, table | абзацы и списки |
| accordion, hotgraphic, narrative, tabs | аккордеон |
| flipcard | переворачивающиеся карточки |
| graphic, dynamic-graphic | подпись-заглушка, если нет текста |
| media, packetTracer | заметка «видео/активность в выгрузку не попали» |
| mcq | вопрос с выбором одного или нескольких |
| dropdownSelect, tableDropdown, fillBlanks, yesNo | выбор из списка в каждой строке |
| objectMatching | сопоставь пары |

Вопросы курса становятся атомами `kind: 'quiz'`: движок показывает их как есть,
не переделывая в другие форматы, но SRS, слабые места и процент раздела работают
так же, как для терминов.

Список того, чего в выгрузке нет (видео, схемы, файлы Packet Tracer),
лежит в `Sources/missing-assets.md`.

## Как устроен контент

Один .md файл курса = один остров = один файл `src/content/mX-Y.ts`.

```
Island
├── lessons[]   вся теория подраздела, блок за блоком, ничего не сокращено
└── atoms[]     единицы знания: термин, факт, перечисление, сценарий для сортировки
```

### Блоки теории (`Lesson.blocks`)

`p` `h` `def` `note` `list` `table` `flip` `accordion` `carousel` `activity` `figure` `transcript`

Типы совпадают с интерактивом на сайте курса: аккордеон остаётся аккордеоном,
карусель каруселью, задание курса остаётся кликабельным заданием с проверкой.

### Атом знания (`Island.atoms`)

```ts
{
  id: '1.1-d1',            // уникальный
  lesson: '1.1.1',         // куда ведёт кнопка «читать теорию» после ошибки
  kind: 'term',            // term | fact | enum | bucket
  term: 'Threat domain',
  definition: 'An area of control, authority, or protection...',
  group: 'domains',        // пул для вариантов ответа, пар и сортировки
  groupLabel: 'Домены угроз',
  ru: 'Русская подсказка',
  cloze: 'A ___ is an area of control...',   // для «дополни утверждение»
  aliases: ['...'],        // что засчитать при вводе с клавиатуры
  items: ['...'],          // только для kind: 'enum'
  bucket: 'INTERNAL',      // только для kind: 'bucket'
  decoys: ['...'],         // ручные ложные варианты
  weight: 3,               // 3 = точно на экзамене
}
```

Движок сам разворачивает один атом в форматы: карточка, выбор термина, выбор
определения, дополни утверждение, верно или нет, ввод с клавиатуры, пары,
сортировка по категориям, выбор всех верных. Формат подбирается по текущему
уровню мастерства: от узнавания к воспроизведению.

### Добавить новый остров

1. Создать `src/content/m1-3.ts` по образцу существующих.
2. Подключить в `src/content/index.ts`: импорт и добавление в `modules`,
   заодно убрать соответствующую строку из `plannedIslands`.
3. `npm run check` — проверит битые ссылки на уроки, дубли id, пустые группы.

## Правила зубрёжки

Урок идёт в два захода:

1. Стопка новых терминов (до 6 карточек), затем основная стопка вопросов.
   Карточка переворачивается нажатием по ней, внизу «Знал» и «Не знал».
2. Экран «Второй заход», затем все промахи первого захода по одному разу.
   Карточки, отмеченные «не знал», возвращаются туда же короткой стопкой.

Карточки уровень терминов не меняют ни в уроке, ни во вкладке «Карточки»:
они только показывают материал и помечают слабые места.

Как считается мастерство термина:

| Когда ответил | Уровень | Вклад в процент темы |
|---|---|---|
| с первого раза | +1 | 100% |
| во втором заходе | без изменений, вернётся раньше | 0%, показывается отдельной строкой |
| не смог дважды | −1, уходит в «Слабые места» | 0% |

- Интервалы повторения по уровням: 10 минут, 1 день, 3 дня, 7 дней, 16 дней, 35 дней.
- Экзамен острова прогоняет **все** термины раздела, второго захода в нём нет. Проходной балл 80%.
- Вкладка «Экзамен» в нижнем меню собирает проверку по выбранным модулям, при полном прогоне ни один термин не пропускается.
- Кнопка с мишенью рядом с подразделом во вкладке «Теория» запускает тренировку только по его терминам.
- Процент острова это средний уровень его терминов и ничего больше. Чтение теории и карточки на него не влияют.
  Разбор показан в приложении: остров, блок «Из чего складывается процент».

## Банк реальных вопросов

`src/content/bank.json` — 953 вопроса курса, распарсенные из `Question_Bank_Clean.md`
скриптом `scripts/import-bank.py`. Теги групп: `M1`–`M27` (модули), `Q1`–`Q7` (квизы
по группам модулей), `end` (итоговый модуль), `F1` (финальный экзамен).

Типы и во что они превращаются на экране:

| В файле | Формат в приложении |
|---|---|
| Multiple Choice | выбор одного варианта |
| Multiple Choice — Select N | выбор нескольких |
| Matching | сопоставь пары |
| Matching — Dropdown | разложи по категориям |

Вкладка «Экзамен» в нижнем меню. Эти прогоны хранятся в отдельном сторе
`src/store/bank.ts` и **не влияют** на процент островов: они меняют только
собственную статистику и список «Мои ошибки». Банк грузится отдельным чанком,
стартовый бандл не тяжелеет.

Перезалить банк из нового .md: `python scripts/import-bank.py` (путь к исходнику
правится в начале скрипта), результат кладётся в `src/content/bank.json`.
